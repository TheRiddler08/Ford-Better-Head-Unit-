# Car Assistant

This is a modified distribution of Home Assistant Core and Home Assistant
Frontend, maintained for this vehicle project. It is not an official Home
Assistant release. The original copyright, attribution and Apache-2.0 licenses
are retained in the copied sources and distributed runtime. Third-party frontend
licenses and notices are generated by the upstream production build.

The original versions, Git revisions and downloaded archive checksums are in
`UPSTREAM.json`. Core contains the complete `homeassistant` runtime package;
upstream Core tests and development infrastructure are omitted. Frontend contains
the matching upstream source tree and build tooling. Existing names and internal
API formats are retained for dashboard/card compatibility.

Our modifications:

- Skip automation, script, cloud, conversation/voice/AI-pipeline and Internet
  alert integrations during startup, including explicit setup requests.
- Remove automation/script configuration API sections and their frontend routes.
- Remove cloud, voice, automation, script, blueprint and area/room management
  routes and settings navigation; hide corresponding dashboard creation shortcuts.
- Keep read-compatible area/floor registries, schemas and imported Python modules
  required by other integrations and existing dashboards. Existing stored data is
  preserved. This is feature removal, not deletion of every shared library file.
- Preserve the native dashboard editor, card implementations, authentication,
  local car entities, history and other integration implementations.

The official image supplies the pinned Python/native dependencies. Our source
package and compiled frontend are copied over that base to make a local derived
image. Docker needs no network to build this image on an offline Tiny. Removing
features does not guarantee a particular hardware boot time.
